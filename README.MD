# Les Simpsons Wiki

## Description
Ce projet est une page web statique dédiée à l'univers des Simpsons. Il présente une page d'accueil avec une navigation simple et du contenu sur la série télévisée, ainsi qu'un article sur Matt Groening, le créateur de la série. Le projet utilise **HTML** et **CSS** pour la mise en page et le style.

## Fonctionnalités
- **Page d'accueil avec navigation** : Un menu de navigation pour accéder aux différentes sections comme l'accueil, le film, les personnages, et l'histoire des Simpsons.
- **Article sur les Simpsons** : Texte détaillé sur l'univers des Simpsons.
- **Article sur Matt Groening** : Une section sur le créateur des Simpsons avec une image et une légende.
- **Style personnalisé** : Utilisation de CSS pour styliser la page avec des couleurs et des mises en page cohérentes.

## Technologies utilisées
- **HTML5** : Structure de base de la page.
- **CSS3** : Design, mise en page, et personnalisation visuelle.
